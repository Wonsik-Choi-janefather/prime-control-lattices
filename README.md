# Prime-Control Lattices

### A Prime-Coordinate Toy Universe: Multiplicative Coding, Beat Channels, and Quantum Control

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21955048.svg)](https://doi.org/10.5281/zenodo.21955048)

**Author:** Won Sik Choi  
**Repository edition:** Preprint Version 1.1 · 16 August 2026

Prime-Control Lattices is a self-contained mathematical toy model in which a finite set of primes indexes coordinate directions in a multiplicative state space. The construction separates the basis freedom of the free abelian group from a distinguished nonnegative-exponent monoid whose atoms select the prime directions.

The paper develops inversion-symmetric prime-shift controls, exact product-ratio mixing, a hypercube of code and beat channels, logarithmic observables, a quadratic logarithmic drift, and finite-dimensional controllability within inversion-parity sectors.

> **Scope.** This is a mathematical control architecture. It does not claim that physical nature is prime-coded, does not rely on the Riemann hypothesis, and does not assert an institutional affiliation.

## Main results

- The multiplicative group alone has a `GL(m,Z)` basis gauge and does not canonically select primes.
- Adding the nonnegative-exponent monoid selects the prime axes as its atoms, uniquely up to permutation.
- Symmetric controls satisfy the exact identity `Q_x Q_y = 1/2 (Q_xy + Q_x/y)`.
- An `m`-prime product produces `2^(m-1)` inversion-identified channels: one forward code channel and `2^(m-1)-1` mixed-sign beat channels.
- A quadratic logarithmic drift gives the bare product-ratio splitting `Omega log(p) log(q)`.
- Every finite hard-wall truncation is fully unitary controllable inside each inversion-parity sector under independently addressable prime-axis controls.
- Inversion symmetry erases orientation, so any physical realization would require an additional preparation or positive-monoid structure.
